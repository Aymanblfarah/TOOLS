# مركز الأدوات الأساسية

موقع عربي بسيط يجمع أدوات يومية في واجهة واحدة:

- حاسبة سريعة
- مؤقت وساعة إيقاف
- محول وحدات
- مولد كلمات مرور
- ملاحظات محفوظة محليًا
- قائمة مهام محفوظة محليًا

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغل خادمًا محليًا من مجلد المشروع:

```bash
python -m http.server 4173
```

ثم افتح:

```text
http://localhost:4173
```

## النشر

المشروع مناسب للنشر عبر GitHub Pages من فرع `main` ومجلد الجذر.
